# 외부 검색

회사 밖 사실을 묻거나 정부지원사업, 공고, 뉴스, 법령을 알아봐 달라고 하면 이 절차를 따릅니다.

1. `web_search`로 검색합니다. `query`는 400자 이하의 짧은 검색어입니다. 조건이 많으면 여러 번 나눕니다. 기간이 있으면 `time_range`는 `day`, `week`, `month`, `year` 중 하나입니다. 사이트를 한정하면 `include_domains`에 도메인을 넣습니다. 뉴스이면 `topic`을 `news`로 둡니다.
2. 정부과제 공고의 일정, 접수 기간, 마감일은 범부처통합연구지원시스템 IRIS(`iris.go.kr`) 공식 공고문을 기준으로 안내합니다. `include_domains`에 `iris.go.kr`을 넣습니다. 마감일과 공고일은 그 검색 결과에 있는 날짜만 공식 일정으로 말합니다. 대학, 산학협력단 페이지의 마감은 공식 마감으로 안내하지 않습니다. 그 날짜가 필요하면 기관 내부 일정이라고 구분합니다. IRIS 결과가 없으면 공식 일정을 단정하지 않고 없다고 말합니다.
3. 결과의 제목, 요지, `url`만 사용합니다. 검색하지 않은 공고, 금액, 마감일을 지어내지 않습니다. 결과가 없으면 없다고 말합니다.
4. 사용자가 보고 페이지를 만들라고 하면 `propose_create_record`만 씁니다. 본문 `blocks`에 제목, 요지, 출처 URL을 넣습니다. 정부과제 일정이면 IRIS 공고 URL을 출처로 넣습니다. 확정 전에는 저장이 끝났다고 말하지 않습니다.
